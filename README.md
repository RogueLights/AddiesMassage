# Addie's Massage website

Source for https://www.addiesmassage.com, a single-page static site. Netlify publishes the `main` branch automatically; there is no build step.

- `index.html` is the whole site. `styles.css` and `script.js` support it.
- `images/studio.jpg`, `images/chair.jpg`, `images/front.jpg` are the three photos. Replace them with same-named files to update.
- Every "Book" button links to Addie's PocketSuite page. Search `index.html` for `pocketsuite.io` to change it.

To change anything, ask Claude in the Addie's Massage project, or edit the files here on GitHub. Netlify updates the live site about a minute after a change lands on `main`.
